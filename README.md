# TEFA Feedlot & Sapi Perah

Website statis tentang TEFA Feedlot & Sapi Perah di Politeknik Negeri Jember yan bertujuan untuk menyebarluaskan informasi mengenai salah satu TEFA (Teaching factory) di Politeknik Negeri Jember yakni TEFA Feedlot & Sapi perah. Saat ini situs hanya bisa dilihat (view-only).

🔗 **Lihat online:** https://raflyarf5.github.io/TEFA_Feedlot/

<img width="1917" height="975" alt="image" src="https://github.com/user-attachments/assets/b825a2e7-d359-4c26-ae4d-e0370ec26895" />


## Fitur

- Menampilkan halaman Layanan yang tersedia pada TEFA Feedlot & Sapi Perah
- Menampilkan halaman Produk yang diproduksi oleh TEFA Feedlot & Sapi Perah
- Tampilan menyesuaikan layar ponsel dan desktop

> **Status:** view-only. Belum ada login, formulir, atau penyimpanan data, untuk melakukan registrasi pendaftaran pada layanan akan dialihkan ke google form. 

## Cara Melihat

### Online

Buka tautan "Lihat online" di atas.

### Di komputer sendiri

Tidak perlu install apa pun.

```bash
git clone https://github.com/username/nama-repo.git
cd nama-repo
```

Lalu buka file `index.html` dengan browser.

Atau jalankan server lokal (opsional, butuh Python):

```bash
python -m http.server 8000
```

Buka http://localhost:8000 di browser.
